# 01 — Product Requirements Document (PRD)
## Pramāṇa AI

**Tagline:** Multi-Agent Research & Fact Verification Platform

---

### 1. Problem

Single-LLM answers hallucinate, mix facts with speculation, and give no way to check reliability. Researchers, students, journalists, and analysts need answers that are traceable to sources and scored for confidence — not just fluent text.

### 2. Core Value Proposition

Instead of one model answering directly, Pramāṇa AI runs a **pipeline of specialized agents** — Research → Verification → Contradiction → Confidence → Citation → Report — so every claim in the final output is checked, scored, and sourced. Transparency over speed.

### 3. Target User

Primary: final-year students, indie researchers, and journalists who need to verify a claim or explore a topic quickly but can't manually cross-check 10 sources. Secondary: developers/analysts who want a research co-pilot with citations they can trust enough to cite further.

### 4. Core Features (Must Have)

- Research topic/question input
- Research Agent — collects claims, sources, facts
- Verification Agent — cross-checks claims against sources
- Contradiction Agent — flags conflicting info / hallucinations / weak evidence
- Confidence Agent — scores each claim 0–100%
- Report Generator — markdown report with citations, confidence badges, summary
- Agent progress view (live pipeline status)
- History of past research sessions
- Auth (Google + Email + Anonymous mode)

### 5. Nice to Have (v2)

- PDF export of report
- Share report via link
- Dark/light mode toggle
- RAG over uploaded documents
- Live internet search (Arxiv, Google Scholar)
- Team workspace / collaboration
- Chrome extension, VS Code extension
- Graph visualization of claim relationships
- Voice-driven research

### 6. Out of Scope (v1)

- Real-time collaborative editing
- Payment / subscription tiers
- Mobile native app
- Multi-language report generation
- Long-term document storage beyond report history

### 7. User Stories

- As a **student**, I want to ask a research question so that I get a verified, cited answer instead of a single unchecked response.
- As a **journalist**, I want to see which claims are contradicted or weakly sourced so that I don't publish unverified information.
- As a **researcher**, I want confidence scores per claim so that I can prioritize which facts need manual double-checking.
- As a **returning user**, I want to see my past research history so that I can revisit or continue earlier work.
- As any user, I want to download the report so that I can use it outside the platform.

### 8. Success Metrics

- End-to-end pipeline (query → report) completes in under 60s for a standard query
- ≥ 80% of generated reports have every claim linked to at least one citation
- 100+ research sessions run during hackathon demo/testing window
- Positive judge/user feedback on report trustworthiness vs plain ChatGPT/Gemini answer
