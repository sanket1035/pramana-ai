# 02 — Technical Requirements Document (TRD)
## Pramāṇa AI

---

### 1. Frontend

- React + Vite + TypeScript
- Tailwind CSS + Shadcn UI
- Framer Motion (animations — typing, streaming, progress, fade)
- Lucide Icons
- TanStack Query (server state / caching)
- React Router (routing)

### 2. Backend

- Node.js + Express + TypeScript
- Layered architecture: Presentation → Business Logic → AI Agents → Database → External APIs

### 3. Database

- Supabase PostgreSQL
- Reason: fast, free tier, built-in Auth, realtime, easy deploy

### 4. Auth

- Supabase Auth
- Google OAuth, Email login, Anonymous mode

### 5. Hosting

| Layer | Provider |
|---|---|
| Frontend | Vercel |
| Backend | Railway |
| Database | Supabase |

### 6. AI Model

- Gemini 2.5 Flash — free tier, large context, fast, cheap. Used across all 5 agents (Research, Verification, Contradiction, Confidence, Citation).

### 7. Third-Party APIs

| API | Purpose | Tier |
|---|---|---|
| Gemini API | Agent reasoning / generation | Free |
| Supabase API | Auth + DB + Realtime | Free |
| Markdown Parser (e.g. `remark`/`marked`) | Render report | Free |
| PDF Generator (e.g. `pdf-lib`/`puppeteer`) | Export report | Free |

### 8. Key Libraries

- Zod (schema validation, request/response typing)
- React Query (data fetching/caching)
- clsx / tailwind-merge (styling utils)

### 10. Environment Variables

```
GEMINI_API_KEY
SUPABASE_URL

```

### 11. Constraints

- Must run fully on free tiers (Gemini free quota, Supabase free tier, Vercel/Railway free tier)
- Must handle Gemini rate limits gracefully (queue/retry in agent pipeline)
- No Docker requirement for local setup (keep onboarding simple)
- Mobile-responsive required; no native app in v1
